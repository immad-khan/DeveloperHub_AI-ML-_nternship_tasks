# 🌸 Task 1: Exploring and Visualizing the Iris Dataset

## 📌 Objective
Load, inspect, and visualize the Iris dataset to understand
data trends and distributions.

## 📦 Dataset
- **Name:** Iris Dataset
- **Source:** Seaborn built-in (`sns.load_dataset('iris')`)
- **Shape:** 150 rows × 5 columns
- **Features:** sepal_length, sepal_width, petal_length,
  petal_width, species

## 📊 Visualizations Used
- Scatter Plot (Sepal vs Petal Length)
- Histograms (Feature Distributions)
- Box Plots (Outlier Detection)
- Pair Plot
- Correlation Heatmap

## 🔍 Key Findings
- Setosa is clearly separable from other species
- Petal length & width are highly correlated
- Virginica has the largest petal dimensions overall

## 🛠️ Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
